# Product
<!-- impeccable:product-schema 1 -->
## Platform
web
## Product Purpose
An Arabic, Bengali, English and Urdu reading space for Riyad as-Salihin, with Quran reading, prayer times and optional personal reminders.
## Users
People reading and studying on phones, tablets and computers.
## Capabilities and Constraints
The user now requests a new combined home overview with Quran, hadith and the current prayer, while preserving exact source religious wording. Extend its visual language to Quran, GPS/city prayer times, floating mobile navigation, verified email accounts, consented approximate locations, owner-only exports and daily/prayer push. Hadith and Quran reminders are five elapsed hours apart. Google uses the existing verified public OAuth configuration. Local browser reading data remains local. Public pages server-render and carry SEO metadata; private data is authenticated and excluded from indexing. The user authorized source pushes to main and publishing the new public reading website. Accounts require a hosted backend; Google must use real OAuth credentials.
## Brand Commitments
Riyad as-Salihin / رياض الصالحين. Retain the approved botanical reading desk identity, typography, garden artwork and an improved daily overview. Different icons distinguish Hadith and Quran navigation.
## Evidence on Hand
Existing repo, imported datasets, source manifests, DATA_SOURCES.md, isolated backend/SSR tests and responsive browser checks.
## Product Principles
Google sign-in is required for app access; policy and source pages stay public. Usage analytics is an optional explicit choice, separate from account and precise-location consent. Keep only the latest consented GPS fix, with reported accuracy, while foreground live location is active. Source provenance stays visible. GPS and notifications follow explicit user gestures and consent. Users can inspect, export and delete their account data. Never invent source text or silently fill translation gaps.
