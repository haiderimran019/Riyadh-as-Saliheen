# Language, theme, and collection guide

## Languages

The Arabic source text is always displayed. The reader loads the selected translation for the current topic; if a record has no selected-language translation, it falls back to English and then to Arabic alone. Language names and coverage counts come from the HadeethEnc language manifest. Translation files are separate per language and are downloaded on request.

Arabic, Urdu, Bengali, Devanagari, and Korean/Latin fallback fonts are bundled locally. No font CDN is used.

## Reading theme

Theme, Arabic size, translation size, and diacritics are stored in local IndexedDB. `system` follows the device color scheme; light, dark, and sepia are explicit overrides. New display settings should be added to the versioned database migration and the live preview in Reading settings.

## Collections

Collection manifests and topic/category trees are generated by the HadeethEnc importer. Keep source records in the ignored `data-local` directory. Do not hand-edit, merge, normalize, shorten, or delete the source text, translations, grades, or commentary. New collections require a documented source and clear redistribution terms before import. Riyad as-Salihin remains out of the bundle until English translation rights are clear.
